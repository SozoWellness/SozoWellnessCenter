## Start here

This ZIP contains the SOZO website that has already been built. Import it into SOZO's own Replit account—there is no need to redesign or rebuild it.

**Your project contact will provide separate, custom instructions for the forms and automations.** Follow those instructions for enquiry handling, email notifications, marketing subscriptions and guide delivery. This document covers the website handoff, not the design of those flows.

Importing the website does not automatically connect the forms or make the site ready to launch.

## What SOZO's team needs to do

1. Create or sign into SOZO's Replit account. SOZO should control the account, billing and access.
2. Open <https://replit.com/import>, choose **ZIP**, and upload the supplied handoff ZIP.
3. Keep all the files together. Do not upload only the images or website folder.
4. Open the website preview and review the pages, images, links and contact details.
5. Obtain the separate custom form and automation instructions from your project contact. Use those instructions to complete the connections before accepting live enquiries.
6. Follow [HANDOFF-CHECKLIST.md](HANDOFF-CHECKLIST.md) and approve the finished site.
7. Connect the clinic's domain only after the website and the intended form/email flows have been tested.

If Replit shows an error or asks about technical setup, share the message with your project contact rather than guessing or changing the design.
